# csharp-intro-notes

C# fundamentals: small console examples and notes I wrote while learning, one folder per topic. Code comments and folder names are in Turkish.

**Status:** Learning archive · **Stack:** C#, .NET Framework, Visual Studio

## Topics

| Folder | Topic |
|---|---|
| 001 – 005 | Hello World, reading input, variables, arithmetic operators, type conversion |
| 006 – 008 | If/else, ternary operator, switch/case |
| 009 – 011 | DateTime methods, array methods, arrays |
| 012 – 014 | Loops: while, do-while, for |
| 015 – 019 | Functions, string methods, methods, try/catch, void methods |
| 020 – 024 | foreach, arithmetic operators, Math class, operator lab exercises, method overloading |
| 025 – 029 | Generic `List<T>`, `out` / `params` / `ref`, recursion, `System.IO`, `ArrayList` |
| 030 | Runtime control (WinForms) |

### Mini projects

- `027-Timer App`: timer app
- `031-Mayın Tarlası App`: Minesweeper
- `032-Kelime Oyunu App`: word game

## Running

Open `C_Sharp.sln` in Visual Studio and set the example you want as the startup project.
